MCP tools

Canonical product names use the strategix_ family. Public discovery is enabled through tools/list; execution is API-key gated during beta.

strategix_visual_contract_create

Create a normalized visual contract from source material, reasoning, or a requested artifact shape.

strategix_visual_contract_validate

Validate canonical visual contracts before rendering. Beta alias: strategix_diagram_validate.

strategix_contract_repair

Repair a contract that fails validation while preserving the original source intent and artifact class.

strategix_render_artifact

Render validated contracts into deterministic visual artifacts with fit reports and receipt metadata. Beta alias: strategix_diagram_render.

strategix_render_html_artifact

Package contract, rendered artifact, source digest, fit report, receipt, and metadata into self-contained HTML. Beta package path: strategix_visual_spec_package.

strategix_fit_report

Check whether the generated artifact matches the source contract, intended class, viewport, and accessibility constraints.

strategix_visual_audit

Inspect a visual artifact for contract drift, missing provenance, layout risk, and publish readiness.

strategix_receipt_create

Create auditable receipt metadata with input, contract, output, route, renderer, and timestamp hashes.

strategix_artifact_search

Search compact visual artifact metadata. Beta alias: strategix_visual_spec_search.
